# Pokemon Explorer

Simple Pokemon app using React, React Router, Tailwind CSS and PokeAPI.

## Features
- Home page: list of Pokemon + search by name
- Detail page: image, types, abilities, stats, moves

## How to run
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Files
- src/App.jsx - header and routes
- src/pages/Home.jsx - list + search
- src/pages/PokemonDetail.jsx - detail page
- src/components/PokemonCard.jsx - one card
